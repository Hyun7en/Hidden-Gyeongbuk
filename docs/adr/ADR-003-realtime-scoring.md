# ADR-003 · 추천 점수 = 요청 시 실시간 계산

**상태** Accepted  
**작성일자** 2026-05-29

## 컨텍스트

사용자 입력은 기간·관심사(복수)·난이도·출발 거점의 조합이며 경우의 수가 매우 많다.

## 결정

코스 추천 점수를 요청 시 실시간 계산한다.

## 근거

입력 조합이 방대해 모든 조합의 코스를 사전 생성·저장하는 비용이 비효율적이다.

## 결과

계산 로직 성능이 응답시간에 직결된다 → 캐시된 장소 데이터 위에서 경량 계산하도록 설계.

## 대안

코스 사전 생성·캐싱 — 입력 조합 폭발로 생성·저장 비용 과다, 데이터 갱신 시 재생성 부담 → 배제.
