# ADR-007 · 응답시간 SLA = 캐싱 후 실측

**상태** Proposed  
**작성일자** 2026-05-29

## 컨텍스트

성능 목표(응답시간)를 정해야 하나 캐싱 구조·실측 데이터가 아직 없다.

## 결정

캐싱 구조 적용 후 실측하여 목표치를 확정한다. (현재 보류)

## 근거

근거 없는 SLA를 미리 확정하면 오히려 개발을 제약한다.

## 결과

성능 측정(WBS P4) 후 수치를 확정하고 본 ADR을 Accepted로 갱신한다.

## 대안

지금 임의 SLA 지정 — 실측 근거가 없어 부정확 → 보류.

## 후속 주석

**2026-07-30** — 본 ADR이 세운 "실측 없는 최적화·목표 설정을 하지 않는다"는 원칙은 ADR-017에서 has_en 비정규화를 재검토하는 근거로도 적용되었다. OI-03(SRS 8장)과 연동되며 여전히 미해결이다.
