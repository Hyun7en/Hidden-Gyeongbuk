# ADR-008 · 관광 빅데이터 = MVP 참고용

**상태** Accepted  
**작성일자** 2026-05-29

## 컨텍스트

TourAPI 빅데이터(방문자수 등)를 추천에 활용할 여지가 있으나 MVP 복잡도를 고려해야 한다.

## 결정

MVP에서는 방문 시기 참고용으로만 사용한다. 본격 분석·지표화는 확장 단계로 미룬다.

## 근거

빅데이터를 핵심 지표로 넣으면 검증·복잡도 부담이 커진다.

## 결과

빅데이터 API는 보조 지표로만 취급한다.

## 대안

빅데이터를 추천 핵심 가중치로 사용 — MVP 범위·검증 부담 초과 → 참고용으로 축소.
