# ADR-004 · 거리·이동 난이도 = Haversine + 등급화

**상태** Accepted  
**작성일자** 2026-05-29

## 컨텍스트

접근성·이동 난이도를 추천 점수에 반영해야 하나 MVP 범위가 제한적이다.

## 결정

좌표 직선거리(Haversine)와 거점–지역 이동 난이도 등급화로 접근성을 산정한다. (MVP)

## 근거

실시간 대중교통 연동 없이 좌표만으로 빠르게 구현 가능하다.

## 결과

실제 이동시간과 오차가 존재한다. 난이도 등급 기준표를 별도 정의해야 한다.

## 대안

실시간 대중교통/길찾기 API로 실제 이동시간 계산 — 구현 복잡·비용·MVP 범위 초과로 확장 과제로 미룸.
