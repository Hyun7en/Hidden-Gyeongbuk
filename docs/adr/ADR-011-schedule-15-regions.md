# ADR-011 · 일정 = 마감 9/21, 15곳 유지

**상태** Accepted  
**작성일자** 2026-05-29

## 컨텍스트

공모전 마감은 2026-09-21로 착수 시점 기준 약 16주가 남았고, 단독 개발이다.

## 결정

9/21 기준으로 WBS를 수립한다. MVP는 경북 인구감소지역 15곳을 전부 유지하되 Hub별 단계 구현으로 리스크를 분산한다.

## 근거

데이터가 TourAPI 기반이라 지역 추가에 드는 수작업 비용이 적어, 16주면 15곳 커버가 가능하다. 지역 축소보다 기능 완성도를 우선한다.

## 결과

WBS에서 프론트 직접 개발 시간을 확보하고, 배포·상용 런칭(제출 요건)을 마감 전에 완료한다.

## 대안

일부 Hub만 MVP로 축소(예: 안동 Hub 먼저) — API 기반이라 확장 비용이 낮아 축소 실익이 적음 → 15곳 전부 유지, 단계 구현.
