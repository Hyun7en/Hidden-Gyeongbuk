# ADR-013 · 영문 콘텐츠 = Google Cloud Translation 전문 번역

**상태** Accepted (ADR-006을 대체)  
**작성일자** 2026-07-17

## 컨텍스트

has_en=false 장소의 영문 보강을 Gemini 2~3문장 요약으로 구현했으나(ADR-006), 실사용 검토에서 요약은 정보 손실이 있고 관광 정보 앱에는 원문을 그대로 옮기는 전문 번역이 더 유용하다고 판단. 또 순수 번역에는 프롬프트 설계·출력 파싱·모델명 변경 리스크가 없는 전용 API가 더 단순·안정적이다.

## 결정

Google Cloud Translation API v2로 국문 제목·설명(3,000자 상한)·주소를 한 번의 호출로 함께 번역해 place_summary(title_en/summary_en/addr_en)에 장소별 1회 캐싱한다. Gemini 무료 티어(일 1,500회)는 향후 챗봇처럼 LLM이 실제로 필요한 기능을 위해 남겨둔다.

## 근거

번역 품질·안정성이 전용 API 쪽이 우수하고, 구현이 단순해진다(프롬프트·파싱 제거). Gemini 모델명이 몇 달 단위로 단종·차단되던 운영 리스크도 사라진다.

## 결과

무료 한도가 월 50만 자인데 전체 백필에 약 100만 자가 필요 — 하루 16,000자 페이스로 분할 진행(완전 무료 유지 결정, 약 2개월 소요). 연속 호출 시 403 userRateLimitExceeded(레거시 v2는 429가 아님)가 나서 호출 간 1초 페이싱 + 해당 에러만 재시도 대상에 포함. 번역 제목은 조회 API의 제목 3단계 폴백(TourAPI 영문 → 번역 → 국문)에도 쓰인다.

## 대안

① Gemini로 번역 계속 — LLM 티어를 번역에 소모하고 프롬프트·모델명 리스크 지속 → 배제. ② 유료 한도 상향으로 며칠 내 백필 완료($10~20) — 가능하나 완전 무료 유지를 우선하기로 결정 → 느린 분할 백필 채택.

## 후속 주석

**2026-07-30** — 본 ADR이 지정한 저장 위치 `place_summary(title_en/summary_en/addr_en)`는 ADR-015에서 폐기되었다. 현재 번역 결과는 `place_translation(place_id, lang, title, overview, addr, source=TRANSLATE)`에 저장한다. 번역 엔진 선택(Google Cloud Translation)과 무료 한도 운영 방침은 그대로 유효하다. 또한 ADR-018에 따라 번역 대상이 영문에 한정되지 않고 언어별로 확장되므로, 문자량 한도는 언어 추가 시 재산정한다.
