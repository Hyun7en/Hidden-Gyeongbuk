# ADR-009 · 인증 = MVP 미적용(익명)

**상태** Accepted  
**작성일자** 2026-05-29

## 컨텍스트

주 사용자는 외국인 단기 방문객이며, MVP는 빠른 탐색·코스 확인이 핵심이다.

## 결정

MVP는 로그인 없이 익명으로 운영한다. 코스 공유는 URL 기반으로 처리한다.

## 근거

로그인은 단기 사용자에게 마찰을 주고 개발량을 늘린다. 익명이면 진입장벽이 낮다.

## 결과

개인화 추천은 확장 단계로 미룬다. 공모전 제출 시 테스트 계정이 불필요한 이점이 있다.

## 대안

로그인/회원제 — 개인화는 가능하나 MVP 범위 초과·마찰 증가 → 익명 채택.
